📘 Overview

This project uses Machine Learning algorithms to predict whether a person is likely to have a particular disease based on health parameters such as glucose level, BMI, age, blood pressure, and more.

The notebook includes data preprocessing, model training, evaluation, and visualization to help understand which factors contribute most to disease prediction.

🚀 Features

🧹 Data Cleaning and Preprocessing

📊 Exploratory Data Analysis (EDA) using Matplotlib & Seaborn

🤖 Model Training with algorithms like Logistic Regression, Random Forest, and SVM

🧩 Model Evaluation (Accuracy, Precision, Recall, F1-Score, ROC-AUC)

📈 Feature Importance Visualization

💾 Model Saving (using Pickle or Joblib)

🧰 Technologies Used

  Python 3.x

  Jupyter Notebook

  NumPy, Pandas

  Matplotlib, Seaborn

  Scikit-learn

  Joblib / Pickle
