# 🧠 Disease Prediction Using Machine Learning

## 📘 Overview
This project uses **Machine Learning algorithms** to predict whether a person is likely to have a particular disease based on health parameters such as glucose level, BMI, age, and blood pressure.  
It includes **data preprocessing, model training, evaluation, and visualization** to help identify key contributing health factors.

---

## 🚀 Features
- 🧹 Data Cleaning and Preprocessing  
- 📊 Exploratory Data Analysis (EDA) using Matplotlib & Seaborn  
- 🤖 Model Training (Logistic Regression, Random Forest, SVM)  
- 🧩 Model Evaluation (Accuracy, Precision, Recall, F1-Score, ROC-AUC)  
- 📈 Feature Importance Visualization  
- 💾 Model Saving using Pickle / Joblib  

---
